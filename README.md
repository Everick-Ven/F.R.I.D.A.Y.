# F.R.I.D.A.Y. — универсальная B2B-разведка и подготовка черновиков для любой ниши рынка РФ

**F.R.I.D.A.Y.** — глубокая российская адаптация открытого проекта [ethanplusai/harvey](https://github.com/ethanplusai/harvey) (MIT License) для **любого сегмента B2B и локального бизнеса в России**: от IT-интеграторов, маркетинговых агентств и логистики/ВЭД до поставщиков оборудования, производства и HoReCa.

---

## Ключевые архитектурные принципы

### 1. Универсальность: Шаг 1 — настройка вашей ниши и продукта (как в Harvey)
Из коробки `friday.yaml` **не привязан ни к одной конкретной отрасли**. Первым шагом система настраивается под ваш бизнес и портрет целевого клиента (ICP):
- **Через ИИ-агента по сайту продукта**: `friday train https://ваш-сайт.рф --niche "кому продаём"` — Python безопасно скачивает страницы сайта (`SafePublicHttpClient`), оборачивает внешний текст в `<untrusted>`, а ИИ-агент рабочей среды генерирует `friday.local.yaml`, `skills/product_knowledge.md` и `skills/competitive_intel.md`.
- **Через веб-интерфейс (`friday ui`)**: вкладка **«1. Ниша и продукт»** с анкетой ICP и примерами шаблонов ниш РФ в 1 клик.
- **Через CLI-шаблон или JSON**: `friday presets` → `friday setup --preset b2b_crm_integrator`.

### 2. Вариант А: ИИ-агент рабочей среды как Мозг (`0 ₽` на ключи LLM)
Вместо платных API-ключей OpenAI/Anthropic или привязки к отдельному платному CLI интеллектуальное ядро работает через **ИИ-агента вашей рабочей среды** (Arena.ai Agent Mode, Cursor, Windsurf, Claude Code и др.):
- **Детерминированный сбор в Python ($0)**: поиск компаний, HTTP-профилирование сайтов Рунета, извлечение русских ФИО/должностей ЛПР и проверка юридического шлюза ФЗ-38 выполняются чистым Python без единого вызова LLM.
- **Пакеты задач (`agent_tasks`)**: обучение нише (`train_niche`), глубокая квалификация (`scout_score`) и написание живых черновиков (`writer_draft`) ставятся в очередь `data/agent_tasks/` + SQLite (`WAL`) и выполняются агентом через `friday tasks next` → `friday tasks apply <id> '<json>'` (или прямо в веб-интерфейсе).

### 3. Российские источники данных и стек Рунета
| Компонент | Что реализовано для рынка РФ |
|---|---|
| **Поиск компаний (`discover`)** | Открытый бесплатный API **HeadHunter (`api.hh.ru`)** по сигнальным вакансиям без ключей, бесплатный веб-поиск Рунета (с отсевом Авито, Ozon, WB, Zoon, 2ГИС, Rusprofile, СБИС и др.), OpenStreetMap по городам РФ, опционально **Яндекс Search API v2** (позиции 11–30), **2ГИС Catalog API**, **Яндекс Карты**, а также импорт CSV/JSON/TXT (выгрузки Контур.Компас, СБИС, 2ГИС, домены `.ru`/`.рф`) |
| **Профайлер сайтов (`profile`, $0)** | **Яндекс.Метрика**, **Яндекс.Директ**, **VK Реклама**, коллтрекинг (**Calltouch, Roistat, CoMagic/UIS, Mango Office**), виджеты CRM и онлайн-записи (**Битрикс24, amoCRM, Jivo, Marquiz, Envybox, YCLIENTS, DIKIDI, Bnovo**), CMS (**Tilda, 1С-Битрикс, InSales, WordPress, MODX, OpenCart, CS-Cart**), мобильная вёрстка, SSL, скорость и ИНН |
| **Поиск ЛПР (`prospects`, $0)** | Извлечение полных русских **ФИО** (*Фамилия Имя Отчество* и *ИП Фамилия И.О.*), вежливое обращение **«Имя Отчество»**, должности ЛПР под выбранную нишу, отделение прямых e-mail от общих `info@` / `sales@` |
| **Комплаенс РФ (`gate.py`)** | Режим **«Разведка + черновики»** без автоотправки (**ст. 18 ФЗ-38 «О рекламе»**), запрет недостоверных превосходных степеней (**ст. 5 ФЗ-38**), опциональные отраслевые пакеты (`medicine` — ст. 24, `finance` — ст. 28, `legal_advocates` — ФЗ-63/КПЭА), IDNA-стоп-лист для доменов `.рф` и `@telegram` |

## Быстрый старт

### 1. Установка
```bash
python3 -m venv .venv
.venv/bin/pip install -e ".[dev]"
```

### 2. Запуск веб-интерфейса
```bash
.venv/bin/friday ui --host 0.0.0.0 --port 5555
```
Откройте веб-интерфейс и начните с вкладки **«1. Ниша и продукт»**.

### 3. Работа через CLI + ИИ-агента рабочей среды
```bash
# Шаг 1. Настроить продукт и целевую нишу (по сайту/брифу или шаблону)
.venv/bin/friday train https://ваш-продукт.рф --niche "оптовые и производственные компании" --brief "..."
# либо мгновенно применить шаблон для теста:
.venv/bin/friday setup --preset b2b_crm_integrator

# Шаг 2. Найти компании (например, бесплатно через открытый API hh.ru по вакансиям), профилировать и найти ЛПР
.venv/bin/friday discover --provider hh_ru -n 15
.venv/bin/friday profile
.venv/bin/friday prospects
.venv/bin/friday score

# Шаг 3. Поставить подготовку черновиков ИИ-агенту рабочей среды
.venv/bin/friday drafts --channel telegram
.venv/bin/friday tasks next
.venv/bin/friday tasks apply <task_id> '<json>'

# Экспорт готовых черновиков в CSV (UTF-8-SIG для Excel / amoCRM / Битрикс24) или Markdown
.venv/bin/friday export --format csv -o drafts.csv
```

## Структура проекта

```text
F.R.I.D.A.Y./
├── friday.yaml                  # Чистый стартовый шаблон конфигурации (до обучения нише)
├── friday.local.yaml            # Активная конфигурация ниши и продукта (создаётся на Шаге 1, gitignored)
├── friday/
│   ├── trainer.py               # Шаг 1: краулер сайта продукта и сохранение ниши + skills/product_knowledge.md
│   ├── brain.py                 # Вариант А: очередь задач ИИ-агента рабочей среды (agent_tasks) + применение JSON
│   ├── state.py                 # SQLite (WAL), компании, ЛПР, observations, триггер signal_codes
│   ├── signals.py               # 28 универсальных сигналов российского рынка
│   ├── gate.py                  # Детерминированный шлюз ФЗ-38 (ст. 5, 18 + отраслевые режимы) и IDNA DNC
│   ├── fit.py                   # Скоринг соответствия целевой нише РФ (0..100)
│   ├── public_http.py           # SSRF-защищённый HTTP-клиент с пиннингом публичных IP
│   ├── untrusted.py             # Защита от Prompt Injection (<untrusted>)
│   ├── collectors/
│   │   ├── discover.py          # hh.ru (без ключей), Яндекс, 2ГИС, Яндекс Карты, DDG/OSM RU, CSV/JSON импорт
│   │   ├── profile.py           # Профилирование сайтов Рунета ($0 HTTP)
│   │   └── people.py            # Поиск русских ФИО, ИП и должностей ЛПР ($0 HTTP)
│   ├── agents/
│   │   ├── scout.py             # Детерминированный скоринг + задачи scout_score для ИИ-агента
│   │   └── writer.py            # Постановка задач writer_draft ИИ-агенту + шаблонный предпросмотр
│   ├── dashboard.py             # FastAPI сервер + REST API
│   └── web/                     # Русскоязычный веб-интерфейс (Шаг 1 «Ниша и продукт» + Центр ИИ-агента)
├── prompts/                     # Системные промпты и JSON-контракты (train, scout, writer)
├── skills/                      # Базы знаний РФ (ФЗ-38, сигналы, фреймворки писем + product_knowledge.md)
└── tests/                       # Набор автотестов pytest
```
