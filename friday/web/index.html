Этапы конвейера ($0 сбор + Мозг Вариант А)

Каждый этап работает независимо через общую SQLite (WAL). Автоматической рассылки нет — система только исследует рынок и готовит проверенные черновики.

Поиск компаний в РФ или импорт файла

Поддерживаются выгрузки Контур.Компас, СБИС, 2ГИС, Rusprofile или текстовый список доменов .ru / .рф.

Мозг F.R.I.D.A.Y. — Вариант А: ИИ-агент рабочей среды

F.R.I.D.A.Y. не требует платных ключей OpenAI/Anthropic или внешнего CLI. Все интеллектуальные задачи (train_niche, scout_score, writer_draft) сохраняются в data/agent_tasks/ и SQLite. Просто попросите ИИ-агента вашей рабочей среды (Arena.ai Agent Mode, Cursor, Windsurf, Claude Code): «Выполни ожидающие задачи F.R.I.D.A.Y. через friday tasks next и friday tasks apply» — либо вставьте JSON-ответ вручную ниже. Каждый черновик при применении автоматически проверяется шлюзом ФЗ-38 (gate.py).

Проверка человеком и ручная отправка 1-на-1 обязательны (ст. 18 ФЗ-38 «О рекламе»)
