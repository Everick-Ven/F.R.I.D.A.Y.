# База навыков (Skills) F.R.I.D.A.Y.

Папка `skills/` содержит редактируемые Markdown-файлы со знаниями по российскому B2B-рынку, работе с сигналами и деловой переписке. Когда ИИ-агент рабочей среды выполняет оценку (`Scout`) или пишет черновики (`Writer`), эти навыки автоматически включаются в контекст задачи.

## Встроенные универсальные навыки (под любую нишу в РФ)

| Файл навыка | Scout | Writer | Назначение |
|---|---|---|---|
| `ru_compliance.md` | ✓ | ✓ | Правила ФЗ-38 «О рекламе» (ст. 5, ст. 18) и опциональные отраслевые ограничения (медицина, финансы, адвокатура) |
| `signal_playbook_ru.md` | ✓ | ✓ | Как переводить сигналы hh.ru, Яндекса, 2ГИС, Яндекс Карт и стека сайта (amoCRM, Битрикс24, Tilda, YCLIENTS и др.) в первую строку сообщения |
| `lead_qualification_ru.md` | ✓ | | Универсальная квалификация российского бизнеса (B2B, услуги, ритейл, производство, IT) |
| `outreach_frameworks_ru.md` | | ✓ | Формулы живого делового аутрича в РФ без спама и ИИ-канцелярита |

## Навыки вашей ниши (создаются на Шаге 1 при настройке ниши / `friday train`)

Эти файлы добавлены в `.gitignore`, чтобы ваши коммерческие настройки оставались приватными:
- `product_knowledge.md` — описание вашего продукта/услуги, болей целевой ниши, кейсов и триггеров покупки;
- `competitive_intel.md` — альтернативы на рынке РФ, отстройка и ответы на частые возражения;
- `outreach_rules.local.md` — ваши персональные правила длины/структуры сообщений (опционально).
