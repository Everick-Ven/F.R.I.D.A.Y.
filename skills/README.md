# Навыки (Skills) F.R.I.D.A.Y.

Папка `skills/` содержит редактируемые Markdown-файлы с предметной экспертизой по российскому юридическому маркетингу. Модули `Scout` и `Writer` автоматически подгружают их при формировании промптов.

## Карта подключения навыков

| Файл навыка | Scout (оценка) | Writer (черновики) |
|---|---|---|
| `fz38_kpea_compliance.md` | ✓ | ✓ |
| `signal_playbook_ru.md` | ✓ | ✓ |
| `lead_qualification_ru.md` | ✓ | |
| `outreach_frameworks_ru.md` | | ✓ |

Вы можете свободно менять формулировки в любом `.md`-файле — изменения подхватятся на следующем запуске без правки Python-кода. Для собственных кастомных правил текста также можно создать `skills/outreach_rules.local.md` (он в `.gitignore`).
