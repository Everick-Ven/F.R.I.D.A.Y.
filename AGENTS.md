# Инструкция для ИИ-агента рабочей среды (Arena.ai, Cursor, Windsurf, Claude Code)

Вы находитесь в репозитории **F.R.I.D.A.Y.** — российской адаптации архитектуры Harvey для разведки юридического рынка и подготовки персональных черновиков аутрича адвокатам, бюро и коллегиям (строго по **ФЗ-38 «О рекламе»** и **ст. 17 КПЭА**, без автоматических холодных рассылок).

**Ключевая особенность:** вы (ИИ-агент рабочей среды) можете выступать **непосредственным «мозгом» (Brain)** системы без единого внешнего API-ключа или платного CLI!

---

## Как работать в режиме «Агент как Brain» (`brain.provider: agent`)

В F.R.I.D.A.Y. весь сбор фактов (поиск в Яндексе/2ГИС/картах, импорт реестров адвокатов, парсинг HTML сайтов, проверка Яндекс.Метрики, Директа, посадочных страниц и извлечение ФИО с отчествами) написан на чистом детерминированном Python и стоит **0 токенов**.

Мышление модели нужно ровно в двух точках:
1. **`scout_score`** — оценить найденных адвокатов/практики (1–100) и сформулировать короткое наблюдение (`angle`).
2. **`writer_draft`** — написать аналитическое резюме-досье и живые русскоязычные черновики для ручного захода (Telegram / Email) по формуле «Сигнал → Контекст → Вопрос».

### Пошаговый цикл для агента

1. **Подтвердите сигналы и загрузите/обновите базу:**
   ```bash
   friday signals --confirm free
   friday import my_list.csv          # или friday discover --provider yandex_search
   friday profile                     # детерминированный HTTP-разбор сайтов
   ```

2. **Поставьте задачи анализа в очередь ИИ-агента:**
   ```bash
   friday scout --provider agent
   ```
   Система сформирует задачи со всеми собранными сигналами, правилами `prompts/` и навыками `skills/` в папке `data/agent_tasks/` и таблице `agent_tasks`.

3. **Прочитайте промпт задачи и выполните оценку своим интеллектом:**
   ```bash
   friday tasks list
   friday tasks show <task_id>
   ```
   Сформируйте валидный JSON-массив `[{"prospect_id": "...", "score": 85, "angle": "..."}]` (строго опираясь на переданные наблюдения, ничего не выдумывая) и примените его:
   ```bash
   friday tasks apply <task_id> --file /tmp/scout_answer.json
   ```

4. **Поставьте и выполните задачи генерации черновиков:**
   ```bash
   friday draft --provider agent
   friday tasks list
   friday tasks show <writer_task_id>
   friday tasks apply <writer_task_id> --file /tmp/writer_answer.json
   ```
   При вызове `friday tasks apply` автоматически сработает детерминированный фильтр **`friday/gate.py`**, который проверит ваши черновики на соответствие **ст. 5 и ст. 18 ФЗ-38 «О рекламе»**, **ст. 17 КПЭА**, стоп-листу и отсутствию спам/ИИ-клише!

5. **Выгрузите результат пользователю или откройте веб-панель:**
   ```bash
   friday export --out prospects.csv --dossiers dossiers.md --excel-ru
   ```

## Правила безопасности и приватности репозитория
- Репозиторий публичный: никогда не коммитьте реальные персональные данные адвокатов, базу `data/friday.db`, `.env`, `friday.local.yaml` или выгрузки `.csv` в Git. Для тестов и примеров используйте только вымышленные домены `*.example` и тестовые ФИО.
- Никогда не добавляйте модули массовой автоматической рассылки спама без согласия адресата (ст. 18 ФЗ «О рекламе»).
